# Knowledge Library index

This index lists every block included in this draft repository. Each block is a compact, testable statement of the Outerprise evidence-delivery model.

1. [Integration Paradox](blocks/integration-paradox.md) — Explains why connecting systems does not by itself establish a shared truth, time, or receipt.
2. [Pair Key / Dual Attestation](blocks/pair-key-dual-attestation.md) — Defines a two-party attestation pattern that keeps content integrity distinct from institutional acknowledgment.
3. [OPD](blocks/opd.md) — Defines an Outerprise Proof Document as a typed evidence envelope with explicit claims, digests, and receipt fields.
4. [Outer-Gration](blocks/outer-gration.md) — Describes an outward delivery boundary where a record leaves one system without inheriting authority from the destination.
5. [Claimed Time vs. Institutional Receipt](blocks/claimed-time-vs-receipt.md) — Separates event time claimed by a sender from time evidenced by a receiving institution.
6. [Evidence Delivery Contract](blocks/evidence-delivery-contract.md) — Provides a minimal protocol and verification checklist for delivery without overclaiming.
